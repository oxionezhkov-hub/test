## 1. Правила анализа рынка

**Запрос:** когда делаем анализ рынка — не писать чепуху, только цифры, цифры выделять жирным; сохранить в скилл/базу знаний/репозиторий.

**Сделано:**
- `.claude/skills/market-analysis/SKILL.md` — скилл. Правила:
  1. Без воды и общих фраз.
  2. Только конкретные цифры: объём, рост (CAGR, % г/г), доли, цены, выручка.
  3. Все цифры **жирным**.
  4. У каждой цифры — год/период и источник.
  5. Нет надёжной цифры — пункт пропускается, не выдумывается.
  6. Только короткие пункты и таблицы.
- `CLAUDE.md` — краткая версия правил со ссылкой на скилл.
- Пункты 4–6 добавлены от себя (можно убрать).
- Правила действуют в сессиях с этим репозиторием; для сессий с main нужно слить ветку.

## 4. Скиллы для экономии токенов и выбора модели

**Запрос:** есть ли скилл, который экономит токены или подсказывает, какая модель нужна.

**Экономят токены:**
- **AgentOne Token Compression** (Iterate.ai) — сжимает подсказки, вывод инструментов, файлы; автор заявляет 40–90% (не проверено). Вмешивается в каждый шаг, отправляет данные на свой сервер.
- **token-saver** (сообщество) — короткие ответы, снимки длинного диалога, база вопросов-ответов между сессиями. Широкие права, анонимный издатель.

**Показывают расход:**
- **token-usage** — разбивка по командам/скиллам/агентам/моделям, история, стоимость.
- **Token Weather Usage** — строка с контекстом, лимитами 5 ч / 7 дней, стоимостью.
- **Turn Usage** — расход каждого хода и доля лимита.

**Встроено в Claude Code:** `/model` (Haiku/Sonnet для простого, Opus для сложного), `/compact`, `/clear`.

**Подсказчика модели в каталоге нет.** Предложено написать свой скилл `model-advisor` (рекомендация модели и уровня рассуждений по типу задачи, с ценами из документации).
