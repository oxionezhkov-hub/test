# Конкурентный анализ

Скиллы в `.claude/skills/`, цепочка:

1. `competitive-profile` → `competitive/company-profile.md` (мы)
2. `competitor-deep-dive` → `competitive/<конкурент>/deep-dive.md` (факты с источниками)
3. `competitor-battlecard` → `competitive/<конкурент>/battlecard.md` (2–3 стр.)
4. `competitor-one-pager` → `competitive/<конкурент>/one-pager.md` (1 стр., можно PDF)

Каждый шаг читает предыдущий. Формат везде — правила `market-analysis`: только цифры, **жирным**, с источником.

Структура повторяет плагин Competitive Intel (Anthropic Directory, автор Karen Ordones); тексты написаны с нуля.
