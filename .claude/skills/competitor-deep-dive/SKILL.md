# Разбор конкурента

## Порядок
1. Прочитать `competitive/company-profile.md`. Нет файла — сначала скилл `competitive-profile`.
2. Собрать данные о конкуренте из открытых источников: сайт и страница цен, отчёты/инвесторские материалы, пресс-релизы, вакансии, отзывы (G2, Capterra, отраслевые), новости за **12 мес.**
3. Записать в `competitive/<slug-конкурента>/deep-dive.md` по шаблону.

## Правила
- Формат по скиллу `market-analysis`: без воды, цифры **жирным**, дата и источник у каждой цифры.
- Каждый факт — со ссылкой. Нет источника — не писать.
- Оценки (не факты) помечать `оценка:` и указывать, из чего выведены.
- Отзывы искажены в сторону недовольных и продвинутых пользователей — указывать размер выборки (**N отзывов**).
