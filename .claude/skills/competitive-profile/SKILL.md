# Профиль нашей компании

Один файл `competitive/company-profile.md` — источник «нас» для `competitor-deep-dive`, `competitor-battlecard`, `competitor-one-pager`.

## Порядок
1. Если файл есть — прочитать и обновить только изменившиеся поля.
2. Если нет — собрать данные у пользователя (из сайта, документов, ответов). Не придумывать: неизвестное поле = `—` и строка в «Открытые вопросы».
3. Записать по шаблону ниже. Формат — правила скилла `market-analysis`: без воды, цифры **жирным**, у цифры — дата и источник.

## Шаблон
```markdown
# Профиль: <Компания>
Обновлено: <ГГГГ-ММ-ДД>

## Ключевые цифры
| Показатель | Значение | Дата / источник |
|---|---|---|
| Выручка / ARR | **…** | … |
| Клиенты | **…** | … |
| Средний чек | **…** | … |
| Сотрудники | **…** | … |
| Рост г/г | **…%** | … |

## Продукт и цены
| Тариф | Цена | Что входит |
|---|---|---|

## Целевой клиент (ICP)
- Сегмент, размер компании (**N–M сотрудников**), регион, роль покупателя

## Наши доказуемые преимущества
| Преимущество | Цифра-доказательство | Источник |
|---|---|---|

## Известные слабые места
```
