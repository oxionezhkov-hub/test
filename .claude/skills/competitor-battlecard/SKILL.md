# Батлкарта

## Порядок
1. Прочитать `competitive/company-profile.md` и `competitive/<slug>/deep-dive.md`. Нет разбора — сначала скилл `competitor-deep-dive`.
2. Новые факты не добавлять: всё берётся из разбора (там источники).
3. Записать `competitive/<slug>/battlecard.md`, объём **≤3 страниц** (~**900 слов**).

## Правила
- Формат по скиллу `market-analysis`: без воды, цифры **жирным**.
- Каждое преимущество — с цифрой. Без цифры — не включать.
- Не принижать конкурента непроверяемыми утверждениями.

## Шаблон
```markdown
# Батлкарта: мы vs <Конкурент>
Обновлено: <дата> · основа: deep-dive.md

## Коротко
| | Мы | Они |
|---|---|---|
| Цена (база) | **…** | **…** |
| Клиенты | **…** | **…** |
| Рейтинг отзывов | **…** | **…** |

## Где выигрываем (топ-3)
1. <преимущество> — **цифра**

## Где проигрываем и что говорить
| Их сила | Наш ответ | Цифра |
|---|---|---|

## Возражения
| Клиент говорит | Ответ | Подтверждение |
|---|---|---|

## Вопросы-ловушки для клиента
- Вопрос, который вскрывает слабость конкурента (их слабость: **цифра**)

## Признаки, что сделка проиграна
- …
```
