# Одностраничник

## Порядок
1. Прочитать `competitive/<slug>/battlecard.md`. Нет батлкарты — сначала скилл `competitor-battlecard`.
2. Сжать до **1 страницы** (~**300 слов**). Новых фактов не добавлять.
3. Записать `competitive/<slug>/one-pager.md`. Нужен PDF — собрать его скиллом `pdf` из этого файла.

## Правила
- Формат по скиллу `market-analysis`: без воды, цифры **жирным**.
- Читается за **30 секунд**: таблицы и короткие строки, без абзацев.

```markdown
# vs <Конкурент> — на звонке
| | Мы | Они |
|---|---|---|
| Цена | **…** | **…** |
| Ключевая метрика | **…** | **…** |

**3 причины выбрать нас**
1. … — **цифра**
2. … — **цифра**
3. … — **цифра**

**Топ-3 возражения → ответ**
- «…» → … (**цифра**)

**2 вопроса клиенту**
- …
```
